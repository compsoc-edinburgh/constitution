# How to build this document

Go to [https://typst.app/open-source/#download] and install the typst compiler.
Its cross-platform and likely available through your package manager, and works
on 

- Windows x86_64, ARM
- MacOS Intel and Apple Silicon
- Linux x86_64, RISC-V, ARMv8 (arm64), ARMv7, if you need the ARMv6l version
    contact skv@sigint.mx

Once installed navigate to this directory and run `typst watch <filename>.typ`
where filename is the name of the file you want to compile. This command will
re-run the compiler whenever you save a change. Open the file in a new terminal
window and edit!

The docs can be found at [https://typst.app/docs/] and if you require plugins
they're at [https://typst.app/universe/].

An online compiler is available here: [https://typst.app/play/]
